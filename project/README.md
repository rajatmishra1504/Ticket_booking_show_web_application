# Ticket_Show_App 

A ticket booking platform which have multiple admin login support.
Basically, this application is made with the motive to provide easy ticket booking system for their favourite show. Also anyone can host their show venue and invite people to book the show. 

For users, they can search the show they want to watch according to their venue , show genre and show name choice.
One can book multiple ticket at a time and also give ratings their booked shows.

An admin can get the statical summary via charts about their venue which they have create and about each show's popularity, booking status, ratings, etc.

####

### Featues of the app :

1. Multi-Admin App
2. Multi-user App
3. Admin registration and login
4. User Registration and login
5. Venue management by Admin i.e. creating new venue, updating venue information, deleting a particular venue
6. Separate dashboard for user and Admin
7. Show management by User i.e. creating new show, updating show information, deleting a particular show
8. Search functonality for shows based on show name, venue name, show genre category
9. User can book show tickets (one time or multiple time and also multiple tickets too)
10. Dynamic changing of seat availability and rating of show after user's booking a show and rating a show respectively.
11. user can see their all bookings and rate it.
12. Admin can see the summary of venue based on the no. of shows each venue is hosting and no. of bookings on each venue
13. Admin can see the summary of each venue based on the no. of bookings of each show and no. of shows of particular genre available at a venue
14. Admin can see the summary of all show based on overall booking and ratings. 
15. A venue can host same show at a particular at two different timings.

#### Technologies used
